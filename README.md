# Arkaleo Web Clipper & Web Notes

Save the web, privately. The Arkaleo Web Clipper allows you to paste any article URL and extract the core content, stripping away ads, trackers, and clutter.

## Capabilities & Features

- **Offline-First Reading**: Articles are saved locally to your device. You can read them anytime, anywhere, completely offline.
- **Tracker-Free**: Because content is extracted and saved as plain Markdown, all external tracking scripts and ad networks are completely removed.
- **Syntax Highlighting**: View and edit the underlying Markdown or HTML with premium, IDE-style syntax highlighting.
- **Undo/Redo Support**: A robust editing mode allows you to modify the saved article, remove unnecessary paragraphs, or add your own thoughts, complete with full undo/redo history.
- **Source Preservation**: The original URL is safely stored in the note's metadata, allowing you to instantly reopen the live web page with a single tap.
- **In-Note Search & TTS**: Just like local notes, you can search through long articles instantly or have Arkaleo read the article aloud to you via Text-to-Speech.
- **Note Info**: View detailed information about the web note, including word count, character count, reading time, and creation details.
